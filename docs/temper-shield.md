# Temper shield

See the excellent documented [Temper git repo](https://github.com/raeedcho/temper).

##  Pins

Pins are like labeled like super!mini (clone of nice!nano)

### Columns

- pinky finger: P031
- ring finger: P029
- middle finger: P002
- index finger: P029 (nicenano P115)
- index aside: P111

### Rows

- top: P022
- middle: P024
- buttom: P100
- thumb: P011


### Usage of i2c display



J2
- 5 - CS -not used
- 4 - GND
- 3 - VCC
- 2 - SCK
- 1 - MOSI SDA


## Nice!Nano
